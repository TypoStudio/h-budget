개인정보 처리방침

가계부 · 시행일 2026년 8월 23일

가계부(이하 “서비스”)는 개인이 비영리로 만들어 무상 제공하는 정적 웹 애플리케이션입니다. 서비스에는 별도의 서버나 데이터베이스가 없으며, 가계부 데이터는 전부 이용자 본인의 구글 스프레드시트에 저장됩니다. 운영자는 이용자의 가계부 내용을 수집하거나 열람할 수 없습니다.

1. 처리하는 개인정보 항목

서비스는 회원가입 절차가 없고, 운영자의 서버로 개인정보를 전송·저장하지 않습니다. 다음 정보만 이용자의 브라우저 또는 구글 서비스 내에서 처리됩니다.

구분항목저장 위치목적
구글 로그인 구글 OAuth 액세스 토큰 이용자 브라우저의 localStorage 구글 스프레드시트 읽기·쓰기 요청 인증, 재방문 시 로그인 유지
서비스 설정 연결한 스프레드시트 ID, 테마 설정, 로그인 동의 여부 이용자 브라우저의 localStorage 다시 접속했을 때 이전 상태 복원
가계부 데이터 월별 수입·지출 금액, 항목명, 메모 이용자 본인의 구글 스프레드시트 가계부 기록·조회
이용 통계 접속 일시, 페이지 조회, 대략적 지역, 브라우저·기기 종류 등 Google Analytics 표준 수집 항목 Google Analytics(구글) 서비스 이용 현황 파악 및 개선

이름, 이메일 주소, 프로필 사진 등 구글 계정의 프로필 정보는 요청하지도, 수집하지도 않습니다.

2. 구글 사용자 데이터의 이용 (Google API Services User Data Policy)

서비스는 구글 로그인 시 아래 권한을 요청하며, 취득한 정보는 Google API Services User Data Policy(제한적 사용 요건 포함)를 준수하여 사용합니다.

요청 권한사용 목적
.../auth/spreadsheets 이용자가 선택하거나 새로 만든 가계부 스프레드시트를 읽고 쓰기 위해 사용합니다. 가계부 항목·금액·메모의 조회와 저장에만 사용됩니다.
.../auth/drive.metadata.readonly 시트 선택 화면에서 이용자의 스프레드시트 목록(파일 이름과 ID)을 보여주기 위해서만 사용합니다. 파일 내용은 이 권한으로 읽지 않습니다.

구글 사용자 데이터에 대하여 서비스는 다음을 준수합니다.

  • 이용자에게 명시한 기능 제공 목적 외의 용도로 사용하지 않습니다.
  • 제3자에게 이전·판매하지 않으며, 광고 목적으로 사용하지 않습니다.
  • 운영자를 포함한 사람이 데이터를 읽지 않습니다. 모든 API 호출은 이용자의 브라우저에서 구글 서버로 직접 이루어지며, 그 사이에 운영자의 서버가 개입하지 않습니다.
  • 인공지능(AI) 모델의 학습에 사용하지 않습니다.

3. 개인정보의 보유 및 파기

  • 액세스 토큰은 구글 정책에 따라 발급 후 약 1시간이 지나면 만료되며, 만료된 토큰은 브라우저에서 자동으로 삭제됩니다.
  • 브라우저에 저장된 설정·토큰은 서비스 내에서 로그아웃하거나, 브라우저의 사이트 데이터 삭제 기능을 이용해 언제든지 즉시 삭제할 수 있습니다.
  • 가계부 데이터는 이용자 본인의 구글 계정에 있으므로, 해당 스프레드시트를 직접 삭제하면 파기됩니다.
  • 서비스에 부여한 구글 계정 접근 권한은 구글 계정 권한 관리 페이지에서 언제든지 철회할 수 있습니다.

4. 제3자 제공 및 처리 위탁

운영자는 개인정보를 제3자에게 제공하지 않습니다. 다만 서비스 운영을 위해 다음 사업자의 서비스를 이용합니다.

  • Google LLC — 구글 로그인, Google Sheets API, Google Drive API, Google Analytics, Firebase Hosting을 통한 웹페이지 호스팅 (구글 개인정보처리방침)

5. 쿠키 및 유사 기술

서비스 자체는 쿠키를 사용하지 않고, 브라우저의 localStorage만 사용합니다. Google Analytics는 방문 통계 집계를 위해 쿠키를 사용할 수 있으며, 브라우저 설정이나 Google Analytics 차단 브라우저 부가기능으로 거부할 수 있습니다. 거부하더라도 서비스 이용에는 제한이 없습니다.

6. 이용자의 권리

이용자는 언제든지 본인 데이터의 열람·수정·삭제를 직접 수행할 수 있습니다. 데이터가 이용자 본인의 구글 계정에 저장되므로, 별도의 요청 절차 없이 스프레드시트에서 직접 처리하거나 로그아웃·권한 철회로 처리를 중단시킬 수 있습니다.

7. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화됩니다.
  • 운영자는 이용자의 구글 비밀번호를 취급하지 않으며, 인증은 전적으로 구글의 OAuth 2.0 절차를 따릅니다.
  • 서버가 없으므로 서버 측 데이터 유출 위험이 존재하지 않습니다. 다만 브라우저에 저장된 토큰 보호를 위해 공용 기기 사용 후에는 로그아웃할 것을 권장합니다.

8. 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.
